# 無効なプラグイン設定

以前の設定や試行用のspecを保管する。このディレクトリはLazyのimport対象でも、
Luaのモジュール探索対象でもない。

再有効化する場合は、APIや依存関係を確認してから
`lua/plugins/<用途>/`へファイルを移す。同じ用途のプラグインが有効なら、担当を整理する。

- `lsp_signature.lua`: シグネチャ表示をBlinkに統一したため無効化。
- その他: 従来importされていなかったspecを集約。`snacks.nvim`はプレビューの
  任意ピッカー依存からも外し、プレビューのピッカーはTelescopeを使う。
